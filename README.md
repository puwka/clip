# Clip Factory

Локальная студия для автоматических нарезок игровых стримов. Интерфейс работает на Next.js и Tailwind. FastAPI принимает записи и запускает обработчик Python/FFmpeg. Исходники, клипы и превью лежат на диске. Supabase хранит очередь, статусы, каталог клипов, настройки и рекламные кампании.

## Запуск на Windows

Понадобятся Node.js 22+, Python 3.11+, FFmpeg и FFprobe с поддержкой `libx264` и `libass`, Ollama и проект Supabase с включённым Data API для схемы `public`.

1. При необходимости установите FFmpeg из PowerShell. Откройте новое окно терминала после установки и проверьте команды `ffmpeg -version` и `ffprobe -version`.

   ```powershell
   winget install --id Gyan.FFmpeg --exact --source winget
   ```

   При ручной установке добавьте папку `bin` в PATH либо задайте абсолютные пути `FFMPEG` и `FFPROBE` в `.env`.

2. Откройте SQL Editor своего проекта Supabase. Выполните содержимое [supabase/schema.sql](supabase/schema.sql). В настройках проекта найдите **Project URL** и серверный **Secret key** (`sb_secret_…`). Поддерживается также прежний ключ `service_role`.

3. В корне проекта подготовьте конфигурацию и зависимости.

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
   npm.cmd ci
   ```

   Заполните `SUPABASE_URL` и `SUPABASE_SECRET_KEY` только в локальном файле `.env`. Используйте отдельный проект Supabase для каждой независимой установки Clip Factory. Одной очереди соответствует одна папка с медиа.

4. Запустите Ollama и загрузите модель. Если Ollama уже работает в области уведомлений Windows, откройте PowerShell и выполните только команду `ollama pull`.

   ```powershell
   ollama pull qwen3.5:4b
   ```

   При ручном запуске держите `ollama serve` в отдельном терминале. В `.env` можно указать другой мультимодальный вариант Qwen 3.5, например `OLLAMA_MODEL=qwen3.5:2b`, и заранее скачать его той же командой. faster-whisper скачивает модель `base` при первой записи с ненулевым звуком. Чтобы скачать её заранее, выполните:

   ```powershell
   .\.venv\Scripts\python.exe -c "from faster_whisper import WhisperModel; WhisperModel('base', device='cpu', compute_type='int8')"
   ```

5. Запустите API и обработчик в первом терминале из корня проекта.

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
   ```

6. Во втором терминале из корня проекта запустите интерфейс.

   ```powershell
   npm.cmd run dev
   ```

   Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). На странице «Настройки» видны подключения API, Supabase, FFmpeg и обработчика. Если порт занят, используйте `npm.cmd run dev -- --port 3100` и задайте `FRONTEND_ORIGIN=http://127.0.0.1:3100` в `.env` перед запуском API. Для изменения порта API согласуйте `--port` и `NEXT_PUBLIC_API_URL`.

Docker не нужен. Для обычного запуска собранного интерфейса используйте `npm.cmd run build`, затем `npm.cmd start`. Оба сервера рассчитаны на использование с того же компьютера и слушают loopback. В браузере используйте адрес с `127.0.0.1`, указанный в `FRONTEND_ORIGIN`.

### Ollama на другом ПК

В разделе «Настройки → Сервер Ollama» укажите адрес API, например `http://192.168.1.20:11434`, и имя установленной мультимодальной модели. Нажмите «Проверить подключение», затем «Сохранить». Настройки хранятся на каждом ПК в `data/ollama.json` (или в каталоге `CLIP_DATA_DIR`). До первого сохранения используются `OLLAMA_URL` и `OLLAMA_MODEL` из `.env`. На клиентском ПК для сетевого режима достаточно запустить Clip Factory.

На ПК с Ollama задайте переменную `OLLAMA_HOST` с локальным сетевым адресом и портом, затем перезапустите Ollama и разрешите вход на этот порт для нужных ПК в частной сети. Для Chrome/Edge CORS на Ollama менять не нужно: подключается FastAPI. Каждый экземпляр отправляет по одному запросу генерации. Запросы от разных ПК принимает общий сервер Ollama, который ставит их в очередь или обрабатывает параллельно в зависимости от конфигурации и памяти. [Документация Ollama по сети и очереди](https://docs.ollama.com/faq)

К адресу Ollama отправляются кадры и распознанные реплики для оценки моментов. Распознавание речи faster-whisper выполняется на ПК с Clip Factory.

### Vercel Services

При потере связи с Supabase готовая локальная задача сохраняет результат и журнал в `data/recovery`. Обработчик повторяет подтверждение завершения после восстановления связи. Если аренда задачи истекла, следующий запуск на том же ПК использует сохранённый результат при совпадении параметров. Настройки и исходные видео должны оставаться в той же папке. Неподтверждённые результаты сохраняются для восстановления. Другой ПК использует собственное хранилище и может обработать задачу повторно. Ollama повторяет временно неудавшиеся запросы до восьми раз с увеличением интервала. Длительный обрыв скачивания или незавершённого анализа может потребовать кнопки «Повторить» в очереди.

`vercel.json` объединяет Next.js и внутренний FastAPI. Браузер вызывает `/api/*` на домене Next.js, а обработчик этого маршрута использует выданный Vercel binding `CLIP_BACKEND_URL`. Для облачного проекта оставьте `NEXT_PUBLIC_API_URL` пустым. Для проверки через `npx vercel dev` временно уберите локальное значение `NEXT_PUBLIC_API_URL` из файла окружения и не задавайте binding вручную.

Облачный режим предназначен для просмотра каталога. Корневой `requirements.txt` используется Vercel, а `backend/requirements.txt` устанавливает полный локальный видеоконвейер. Для подключения реальной базы настройте Deployment Protection и добавьте серверные переменные `SUPABASE_URL` и `SUPABASE_SECRET_KEY` через Vercel. Полный конвейер требует постоянно работающего обработчика, общего постоянного хранилища и отдельного пути для больших загрузок. Загрузка, очередь обработки и изменение настроек доступны в локальном режиме. [Vercel Services](https://vercel.com/docs/services) · [Лимиты Vercel Functions](https://vercel.com/docs/functions/limitations)

## Конвейер

1. Откройте «Конвейер» и загрузите файл либо импортируйте запись по прямой публичной HTTP(S)-ссылке с разрешения владельца. Временные ссылки на файл поддерживаются. Страницы плееров, плейлисты и адреса, которым нужны браузерная авторизация или закрытая сеть, отклоняются.
2. После загрузки ИИ-анализ начинается автоматически. В очереди видны прогресс и ошибки скачивания, анализа и экспорта. Неудавшуюся задачу можно повторить. Если временная ссылка истекла, создайте импорт с новой ссылкой. Адрес с параметрами хранится локально до завершения импорта. В Supabase записывается только имя хоста и состояние задачи.
3. У готовой записи нажмите «Выбрать моменты». Отметьте нужные клипы и перейдите в Auto Editor. Настройте кадрирование, субтитры, заголовок и при необходимости выберите действующую рекламную кампанию.
4. Соберите один ролик или выберите пакетный экспорт. В пакете каждый выбранный фрагмент становится отдельным MP4 с общими параметрами монтажа и рекламы. Для каждого файла доступны его прогресс, предпросмотр и повторный запуск. ZIP содержит готовые файлы пакета на момент скачивания.

Скачивание по ссылке идёт отдельно от очереди анализа и монтажа. Исходники, клипы, баннеры и готовые MP4 сохраняются локально. Для обновления конвейера существующей установки выполните [supabase/schema.sql](supabase/schema.sql) и перезапустите API и интерфейс.

### Запись Twitch

В локальном «Конвейере» доступен отдельный «Архив стрима · каждые 2 часа». Укажите канал и существующую папку на подключённом диске. Архив пишет лучший доступный поток без перекодирования в TS/MKV, отдельными двухчасовыми файлами. Разделение происходит на ближайшем ключевом кадре после двух часов, последний файл при остановке может быть короче. Архив запускается параллельно записи для нарезки через отдельное подключение к Twitch и не ставится в очередь анализа. Папка сохраняется на этом ПК. При обрыве связи текущий файл закрывается, затем идут повторные подключения до ручной остановки. При отключении диска или достижении резерва свободного места запись останавливается. Пропущенные при обрыве трансляции данные восстановить невозможно. После перезапуска приложения архив нужно запустить снова.

1. Выполните обновление схемы и установите зависимости из `backend/requirements.txt`. В «Настройках» выберите 15 или 60 минут и сохраните настройки.
2. В «Конвейере» вставьте ссылку на Twitch-канал, запись которого разрешена. Если нужен баннер, выберите действующую кампанию. Нажмите «Начать запись».
3. По мере закрытия файлов в «ИИ-анализе» появляются записи Twitch. Найденные моменты доступны как горизонтальные нарезки. Выберите фрагменты и настройте экспорт в «Монтаже». «Остановить запись» сохраняет текущий сегмент.

Streamlink выбирает лучший доступный поток. FFmpeg через PyAV переносит дорожки в локальные файлы без перекодирования. Граница ставится на первом ключевом кадре на отметке 15 или 60 минут либо после неё. Смена режима применяется к файлу, который откроется следующим. После обрыва приложение закрывает текущий файл и пытается снова подключиться. Данные, которые Twitch пропустил во время обрыва, восстановить из локальной записи невозможно.

Запись останавливается при достижении резерва `TWITCH_DISK_RESERVE_GB` (по умолчанию 5 ГиБ) или лимита `CLIP_MAX_UPLOAD_GB` на сегмент. Записи хранятся в `data/sources`, а сведения о сегментах, ожидающих постановки в очередь анализа, — в `data/twitch`. Закрытые файлы подхватываются после перезапуска API.

### Обновление существующей установки

Повторно выполните [supabase/schema.sql](supabase/schema.sql), установите зависимости из `backend/requirements.txt`, запустите Ollama с нужной моделью и перезапустите API и интерфейс. Для старой записи на странице «Источники» доступна кнопка «Анализировать заново». Прежние клипы заменяются после успешного завершения повторного анализа.

## Работа в студии

- В «Настройках» выберите целевую длину клипа от 15 до 45 секунд. Настройка фиксируется при загрузке.
- Загрузите локальную запись в MP4, MOV, MKV, WEBM, AVI, FLV, M4V или TS. Лимит по умолчанию — 20 ГБ, длительность — от 15 секунд до 24 часов. FFprobe проверяет наличие видеодорожки и длительность.
- Обработчик разбирает запись двухминутными частями с перекрытием. Faster-whisper распознаёт реплики, а измерения громкости, коротких звуковых пиков и различий между кадрами помогают выбрать кандидатов по всей записи. Qwen 3.5 оценивает до 36 кандидатов по репликам, звуковым признакам и кадрам около события. Возможные категории включают смешной момент, крик, аварию и неожиданность. В записи без звука используются кадры и движение.
- На странице «Источники» откройте «Нарезки» у готовой записи. Список содержит до 10 непересекающихся фрагментов по 15–45 секунд, отсортированных по оценке. У каждого есть таймкод, оценка 0–100, краткое объяснение, предпросмотр и скачивание. Число клипов зависит от длины записи и расположения кандидатов. Оценку и категорию можно сверить по видео.
- Новые нарезки скачиваются в 16:9 как MKV с видео FFV1 без потерь и звуком PCM. Исходный кадр сохраняется целиком, а при другом соотношении сторон добавляются поля. Для просмотра в браузере используется отдельный MP4. Вертикальный экспорт создаётся в «Монтаже» с выбранными там настройками.
- Кампанию можно назначить источнику при загрузке или позже. На её карточке есть ссылки на сгруппированные источники и нарезки. Рекламу для готового ролика выбирайте отдельно в Auto Editor.
- После аварийной остановки незавершённая задача снова становится доступна обработчику по истечении двухминутной аренды. На странице «Источники» можно прочитать сообщение об ошибке и запустить задачу повторно.

## Auto Editor

1. В разделе «Нарезки» нажмите «В монтаж» у нужных клипов, затем откройте Auto Editor. Измените порядок фрагментов стрелками. Можно собрать отдельный Shorts из одного фрагмента или монтаж из нескольких.
2. Выберите полноэкранное кадрирование по центру или задайте центр вручную. Положение кадра фиксируется на фрагмент. Промежуточные кадры сохраняются без потерь, а итоговое видео один раз кодируется H.264.
3. Укажите язык речи и вид субтитров. Реплики по таймкодам слов занимают до трёх строк в безопасной зоне. На Windows субтитры используют Segoe UI, прописные буквы и тонкую тёмную обводку. Размер по умолчанию 62 px. Средняя строка трёхстрочной реплики немного крупнее и по умолчанию жёлтая. Реплики для сверки со звуком помечаются в отчёте рендера. Если начало или конец пересекает распознанное слово, монтаж привязывает границу к ближайшей паузе. Заголовок занимает до двух строк и показывается до трёх секунд. Для нескольких фрагментов доступны прямая склейка, плавное смешивание и переход через чёрный.
4. Нажмите «Собрать Shorts». MP4 1080 × 1920, 30 кадров/с, H.264/yuv420p и AAC 48 кГц доступен из истории экспорта. Монтаж использует исходную первую аудиодорожку. После склеек громкость нормализуется двухпроходным loudnorm до цели −16 LUFS-I с контролем потолка −1,5 dBTP после кодирования. Ролик длится до трёх минут по [формату YouTube Shorts](https://support.google.com/youtube/answer/15424877).

Auto Editor берёт видео из папки исходников и распознаёт таймкоды слов локально через faster-whisper. Экспорт хранится в `data/shorts`, а его настройки и статус — в Supabase. Чтобы добавить Auto Editor к уже настроенной установке, повторно выполните [supabase/schema.sql](supabase/schema.sql) и перезапустите API и интерфейс.

Если в записи есть веб-камера, включите «Есть веб-камера» при загрузке, импорте или старте записи Twitch. Для существующей записи откройте «Источники» → «Веб-камера». Можно выделить прямоугольник на исходном кадре или сбросить выделение для автоматического поиска лица. При неуверенном определении редактор попросит выбрать область и создать новый экспорт. Настройки сохраняются в момент постановки экспорта в очередь. В шаблоне с камерой игра заполняет вертикальный кадр с сохранением пропорций, а камера накладывается сверху слева. Если кадрирование захватывает исходную врезку камеры, она также видна в игровом кадре.

## Рекламные кампании

1. На странице «Рекламные кампании» создайте кампанию, укажите рекламодателя, промокод, CPM с валютой, период и план просмотров. Прогноз равен `просмотры × CPM / 1000`. Это оценка для введённых просмотров и ставки.
2. Загрузите статичный PNG или WebP до 10 МБ. Настройте ширину, позицию, непрозрачность и время показа. Пустое время окончания означает показ до конца ролика. Промокод можно вывести под баннером.
3. В Auto Editor выберите активную кампанию с баннером и действующим периодом. Для конкретного ролика можно изменить размещение и ожидаемые просмотры. По умолчанию выбрано «Без рекламы».

Размер и позиция рассчитываются внутри рекламной полосы над игровым видео, отдельно от заголовка и субтитров. Общий режим использует пересечение зон Shorts и TikTok. Это консервативные ориентиры для вертикальной ленты. Расположение элементов ленты зависит от устройства и формата. [Ориентиры Shorts](https://support.google.com/google-ads/answer/9128498), [ориентиры TikTok](https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads).

Баннер накладывается на итоговый таймлайн после склеек. При постановке задачи в очередь сохраняются версия баннера, параметры, промокод и ставка. Баннеры лежат в `data/banners`. При обновлении существующей установки установите зависимости из `backend/requirements.txt`, повторно выполните [supabase/schema.sql](supabase/schema.sql) и перезапустите приложение.

## Хранение и диагностика

- `data/sources` содержит исходные видео, `data/clips` — MP4 и JPEG. `CLIP_DATA_DIR` принимает относительный или абсолютный путь. Для переноса системы переносите и папку медиа, и метаданные Supabase.
- `CLIP_MAX_UPLOAD_GB` задаёт лимит файла. На диске должно быть место под исходник и клипы.
- [FastAPI /health](http://127.0.0.1:8000/health) показывает диагностику, [FastAPI /docs](http://127.0.0.1:8000/docs) — схему API. Для запросов записи из локальных скриптов передавайте заголовок `X-Clip-Factory: local`. Ollama по умолчанию доступна на `127.0.0.1:11434`. В Supabase сохраняются оценки и метаданные клипов, а распознанные реплики и кадры передаются только локальной Ollama при настройках по умолчанию.
- При ошибке подключения проверьте Project URL, серверный ключ, включение Data API и выполнение SQL. Схема включает RLS и ограничивает доступ к данным серверной ролью Supabase.

Справка по [faster-whisper](https://github.com/SYSTRAN/faster-whisper), [Qwen 3.5 в Ollama](https://ollama.com/library/qwen3.5), [ключам Supabase](https://supabase.com/docs/guides/getting-started/api-keys) и [сборкам FFmpeg для Windows](https://ffmpeg.org/download.html#build-windows).
